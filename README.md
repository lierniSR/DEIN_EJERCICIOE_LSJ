Este programa visualiza una tabla vacia y 3 botones: Añadir, modificar y eliminar.
Añadir --> Añade una nueva persona a la tabla. Los datos se pediran mediante una ventana modal.
Modificar --> Modifica una persona seleccionada de la tabla. Los datos se visualizan en la ventana modal que se abre y en esa misma se modificaran los datos.
ELimina--> Solo sale una alerta de que la Persona se a eliminado y se elimina de la tabla.
